Topology is the physical and logical structure of connection between nodes(PCs, Laptop, Mobile) and It explains how devices are connected to one another in network and how data flows through that structure.

## Types Of Topologies
### Mesh Topology
A devices directed  connect to another device with each other.
![[Pasted image 20260915124433.png]]

#### Features
- High Reliability if one wire damaged so it communicate through another path.
- Point to Point communication
- High Security because data transfer direct to the destination without passed through other path.
#### Draw Back
- High Cost & Maintenance because large number of wire needed.
### Star Topology
In this topology, Devices are directly connect with central device( hub/switch ).
![[Pasted image 20260915124929.png]]

#### Features
- Point to Point connection.
- Low Cost than mesh.
- Easy to maintenance it.
#### Draw Back
- Low Reliability because if central device damaged so communication break.
- Less security than mesh because data passed through the central device ( switch (High Security), hub(Less Security) ) then its destination device.
### Bus Topology
In this topology, a single backbone thick wire and the device connect with this cable through drop line and tap
![[Pasted image 20260915131641.png]]

#### Features
- Multi Point connection, data passed through all device
- Low Cost and Easy to maintenance
- Terminator/Repeator is use increase the signal strength.
#### Draw Back
- Less Security because data passed through all device.
- Low Reliability, if the single backbone cable damaged so entire communication stopped.
### Ring Topology
In this topology, devices are connect in ring shape through single ring shape cable
![[Pasted image 20260915132832.png]]

### Features
- Data flow in one direction
- Token passed system to reduce collision.
- low cost and easy to maintenance same as bus topology
### Draw Back
- High Collision, if all device in that topology communicate at same time.
- Less Secure because data flow in one direction and passed from all devices
- Less Reliability, if backbone cable damaged so entire network down.
### Hybrid Topology
The combination of different topologies like mesh, ring, bus, star is called hybrid topology.
![[Pasted image 20260915141337.png]]

#### Features
- It's give us combine benefits of all topologies.
- High Flexibility because we can expand it by joint more topologies through routers, switches, hubs
- High Reliability
#### Draw Back
- High Cost & Complexity because we need routers, switches, hubs to connect other topologies.
