## IP Address(Internet Protocol Address)
- **What's this :** It's logical address that assign by our adminstator, router and ISP.
- **Length / Format :**
  1. **IPV4 :** It's 32bits IP Address represented by dotted decimal e.g 192.168.1.1.
  2. **IPV6 :** It's 128 bits IP Address represented by hexadecimal e.g 2345:0425:2CA1:0000:0000:0567:5673:23b5
