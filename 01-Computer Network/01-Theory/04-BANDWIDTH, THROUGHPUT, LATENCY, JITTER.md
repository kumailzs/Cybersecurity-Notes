## Bandwidth
A maximum theoritical data packets that can transfered over the network in per second usually measured in mbps or gbps.
## Throughput
A actual data packet that can successful transfered across the network channel in per second.
## Latency
The time delay/taken( measured in ms ) required for the data packet to travel from source to destination.
## Jitter
The continuously changes in latency over the time when consecutive data packet arrive in different speed (2ms, 5ms, 7ms).
